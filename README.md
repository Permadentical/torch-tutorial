# torch-tutorial

A self-learning journey to creating a PyTorch tutorial, along with my mistakes and my fixes.

## Prerequisites

-   Ideally get Conda (<https://anaconda.org/anaconda/conda>)
    -   miniconda also should work
-   Ideally set-up an environment for this tutorial pack
-   Run `pip install -r requirements.txt`
    -   If you want to use GPU, probably best to install torch according to:
        -   <https://pytorch.org/>
-   Dive in

## The Basics

Access _**the-basics**_ folder. I go over:

1. Tensor Basics
2. Tensor Operations and Arithmetic
